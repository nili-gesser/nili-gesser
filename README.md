# Nili Gesser Academic Website

This is a simple static academic website built for GitHub Pages.

## Files

- `index.html` — the main website content
- `style.css` — the visual design and responsive layout
- `README.md` — this guide

## How to edit the site

Open `index.html` in any text editor and edit the text inside each section:

- Hero
- About
- Research Interests
- Current Projects
- Selected Publications
- Teaching
- Talks & Conferences
- Contact

Open `style.css` to change colors, fonts, spacing, or layout.

The main purple colors are defined near the top of `style.css`:

```css
--purple-dark: #3b1f5c;
--purple: #6d3fb3;
--purple-light: #f3ecff;
```

## How to publish with GitHub Pages

1. Create a GitHub account or log in to GitHub.
2. Create a new repository. A good name is `nili-gesser.github.io` or `academic-website`.
3. Upload these three files to the repository:
   - `index.html`
   - `style.css`
   - `README.md`
4. Go to **Settings** → **Pages**.
5. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
6. Click **Save**.
7. GitHub will publish the site and provide a public link.

## Notes

This website uses only HTML and CSS. It does not use JavaScript, React, Python, or a backend.
